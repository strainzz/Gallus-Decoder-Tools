# Security

Gallus Decoder Tools calculates on the machine where it is installed. It does not take a key, hold an account, or call a network.

Report a vulnerability through a private GitHub security advisory on this repository. Include the version, the command, and the input that shows the problem.

Use a public issue for an ordinary defect, such as a wrong cipher total or a date the parser rejects. Leave exploit detail out of public issues.
